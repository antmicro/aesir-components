# Aesir CSS

Generated tokens, motion, typography, and webfonts shared by Aesir distributions.

```js
import '@aesir/css/aesir-global.css';
import '@aesir/css/aesir-motion.css';
import '@aesir/css/aesir-themes.css'; // Optional theme presets
```

`aesir-typography.css` is optional. Themes and fonts are available through their package exports.
